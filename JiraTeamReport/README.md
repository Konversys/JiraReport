# Jira Team Report

Небольшое WPF-приложение для отчета по дням и сотрудникам команды Tempo. В строках отображаются даты периода, в столбцах — активные сотрудники команды (включая тех, у кого в периоде нет worklogs). В ячейке показываются только названия задачи с максимальным worklog и Epic Link с наибольшей суммой за день. Ссылки на задачу и Epic Link открывают Jira.

## Запуск

Откройте `JiraTeamReport.sln` или выполните из корня репозитория:

```powershell
dotnet run --project JiraTeamReport/JiraTeamReport.csproj
```

Требуются Windows и .NET 10 Desktop Runtime.

## Подключение

Введите базовый URL Jira, имя пользователя и пароль. Приложение использует эти учетные данные для Jira REST API и Tempo REST API с Basic Authentication; отдельный Tempo API-токен не нужен. Поддерживается Jira Server/Data Center с установленным Tempo Timesheets.

Jira Cloud в таком режиме не поддерживается: Tempo Cloud REST API требует отдельной авторизации Tempo. При включенной опции данные подключения сохраняются между запусками; пароль хранится в Windows Credential Manager. Вкладка «Логи API» показывает запросы и ответы для отладки; заголовок авторизации не записывается, лог хранится в памяти и ограничен последними 500 записями.

## Примечания

- Время группируется по локальной календарной дате worklog.
- Worklogs без Epic Link рассматриваются как отдельная группа.
- Epic Link определяется по метаданным Jira и динамическому ID custom field. Если метаданные недоступны, используются стандартные ID `customfield_10014` и `customfield_10008`.
